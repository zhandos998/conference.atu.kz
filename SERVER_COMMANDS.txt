Check Docker on server

  nginx -v

If Docker is not installed on Ubuntu:

  sudo apt update
  sudo apt install -y ca-certificates curl gnupg git nginx
  sudo install -m 0755 -d /etc/apt/keyrings
  curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
  sudo chmod a+r /etc/apt/keyrings/docker.gpg
  echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
  sudo apt update
  sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
  sudo systemctl enable --now docker
  sudo usermod -aG docker zhagparovr

After usermod, reconnect to SSH.


First deploy from Git
---------------------
Prepare project folder on server:

  ssh zhagparovr@172.20.252.171
  sudo mkdir -p /opt
  sudo chown zhagparovr:zhagparovr /opt
  rm -rf /opt/conference.atu.kz
  git clone --branch main https://github.com/zhandos998/conference.atu.kz.git /opt/conference.atu.kz
  cd /opt/conference.atu.kz


Create .env on server
---------------------
  cd /opt/conference.atu.kz
  cp -n .env.example .env
  nano .env

Set real values:
  APP_NAME="Conference ATU"
  APP_ENV=production
  APP_DEBUG=false
  APP_URL=https://conference.atu.kz
  FRONTEND_URL=https://conference.atu.kz
  FRONTEND_BIND=127.0.0.1
  FRONTEND_PORT=8094
  PHPMYADMIN_PORT=8095
  PHPMYADMIN_UPLOAD_LIMIT=64M
  DB_CONNECTION=mysql
  DB_HOST=db
  DB_PORT=3306
  DB_DATABASE=conference
  DB_USERNAME=conference
  DB_PASSWORD=<strong_mysql_password>
  MYSQL_DATABASE=conference
  MYSQL_USER=conference
  MYSQL_PASSWORD=<same_strong_mysql_password>
  MYSQL_ROOT_PASSWORD=<strong_mysql_root_password>
  SESSION_DRIVER=database
  CACHE_STORE=database
  QUEUE_CONNECTION=database
  FILESYSTEM_DISK=public
  MAIL_MAILER=smtp
  MAIL_HOST=<mail_host>
  MAIL_PORT=587
  MAIL_USERNAME=<mail_username>
  MAIL_PASSWORD=<mail_password>
  MAIL_SCHEME=tls
  MAIL_FROM_ADDRESS=conference@atu.edu.kz
  MAIL_FROM_NAME="${APP_NAME}"

Generate APP_KEY on server:

  APP_KEY="base64:$(openssl rand -base64 32)"
  sed -i "s|^APP_KEY=.*|APP_KEY=${APP_KEY}|" .env
  chmod 600 .env

Check required values:

  grep -E '^(APP_KEY|APP_URL|FRONTEND_PORT|PHPMYADMIN_PORT|MYSQL_DATABASE|MYSQL_USER)=' .env


Build and start Docker
----------------------
  cd /opt/conference.atu.kz
  docker compose up -d --build --remove-orphans
  docker compose ps

The backend container automatically runs:
  php artisan storage:link --force
  php artisan migrate --force
  php artisan config:cache
  php artisan view:cache


Run Laravel setup manually if needed
------------------------------------
  cd /opt/conference.atu.kz
  docker compose exec backend php artisan migrate --force
  docker compose exec backend php artisan storage:link --force
  docker compose exec backend php artisan optimize:clear
  docker compose exec backend php artisan config:cache
  docker compose exec backend php artisan view:cache

Create or reset moderator password if needed:
  docker compose exec backend php artisan tinker

Then in tinker:
  $newPassword = '<new_moderator_password>';
  $user = App\Models\User::firstOrCreate(['email' => 'moderator@atu.kz'], ['name' => 'Moderator', 'role' => 'moderator', 'email_verified_at' => now()]);
  $user->forceFill(['password' => Hash::make($newPassword), 'role' => 'moderator', 'email_verified_at' => now()])->save();
  exit


Nginx reverse proxy on server
-----------------------------
Create config:

  sudo nano /etc/nginx/sites-available/conference.atu.kz

Paste:

  server {
      listen 80;
      listen [::]:80;
      server_name conference.atu.kz www.conference.atu.kz;

      return 301 https://conference.atu.kz$request_uri;
  }

  server {
      listen 443 ssl;
      listen [::]:443 ssl;
      server_name conference.atu.kz www.conference.atu.kz;

      ssl_certificate /etc/ssl/atussl/ssl-bundle.crt;
      ssl_certificate_key /etc/ssl/atussl/atu.key;
      ssl_prefer_server_ciphers on;

      client_max_body_size 64M;

      access_log /var/log/nginx/conference_access.log;
      error_log /var/log/nginx/conference_error.log;

      location / {
          proxy_pass http://127.0.0.1:8094;
          proxy_http_version 1.1;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
          proxy_set_header X-Forwarded-Host $host;
          proxy_set_header X-Forwarded-Port $server_port;
          proxy_set_header Upgrade $http_upgrade;
          proxy_set_header Connection "upgrade";
      }
  }

Enable:

  sudo ln -sfn /etc/nginx/sites-available/conference.atu.kz /etc/nginx/sites-enabled/conference.atu.kz
  sudo nginx -t
  sudo systemctl reload nginx

Database
--------
Open MySQL CLI:
  cd /opt/conference.atu.kz
  docker compose exec db sh -c 'mysql -u"$MYSQL_USER" -p"$MYSQL_PASSWORD" "$MYSQL_DATABASE"'

Backup database on server:
  cd /opt/conference.atu.kz
  docker compose exec db sh -c 'mysqldump -u"$MYSQL_USER" -p"$MYSQL_PASSWORD" "$MYSQL_DATABASE"' > conference-backup-$(date +%F-%H%M).sql

Restore database from backup:
  cd /opt/conference.atu.kz
  docker compose exec -T db sh -c 'mysql -u"$MYSQL_USER" -p"$MYSQL_PASSWORD" "$MYSQL_DATABASE"' < conference-backup.sql

Copy database backup from server to local machine:
  scp zhagparovr@172.20.252.171:/opt/conference.atu.kz/conference-backup.sql .


Storage files
-------------
Uploaded files are stored in Docker volume:
  backend_storage

Backup uploaded files on server:
  cd /opt/conference.atu.kz
  STORAGE_VOLUME="$(docker volume ls --format '{{.Name}}' | grep '_backend_storage$' | head -n 1)"
  docker run --rm -v "${STORAGE_VOLUME}:/data" -v "$PWD":/backup alpine tar czf /backup/conference-storage-$(date +%F-%H%M).tar.gz -C /data .

Restore uploaded files on server:
  cd /opt/conference.atu.kz
  STORAGE_VOLUME="$(docker volume ls --format '{{.Name}}' | grep '_backend_storage$' | head -n 1)"
  docker run --rm -v "${STORAGE_VOLUME}:/data" -v "$PWD":/backup alpine sh -c 'cd /data && tar xzf /backup/conference-storage.tar.gz'

If the Docker volume name is different, check it with:
  docker volume ls | grep backend_storage
